📧 Stopka mailowa — jak użyć

Gmail (web):

  1. Zaznacz stopkę poniżej (Cmd+A w jej obrębie) → kopiuj (Cmd+C)
  2. Gmail → ⚙️ Settings → See all settings → General → Signature
  3. Create new → nazwa „isiko" → wklej (Cmd+V) → Save

Gmail (iPhone app):

  1. Otwórz tę stronę na iPhone'ie w Safari
  2. Zaznacz + kopiuj stopkę
  3. Gmail app → Menu (☰) → Settings → Tap konto → Signature settings → Mobile Signature → wklej

iPhone Mail (natywna apka):

  1. W Safari na iPhone → zaznacz i kopiuj stopkę
  2. Settings → Mail → Signature → wklej
  3. Ważne: trzymaj palec na tekście po wklejeniu → wybierz „Paste as Rich Text" (jeśli pokaże się opcja)

Outlook / Apple Mail (desktop):

  1. Zaznacz stopkę → kopiuj
  2. Preferences → Signatures → New → wklej
  3. Odznacz „Always match my default message font" w Apple Mail
